REAL VALUE

お客様の、
本当の困りごとを見つける。

「何がほしいか」の奥に、「何を前へ進めたいか」があります。そこに耳を傾けることが、選ばれ続けることにつながる。そんな考え方を、手順にしてみました。

  • 要望の奥を聴く
  • AIを使わない案も
  • 成果は複数の面で

IN 30 SECONDS

30秒でわかる要点。

  • お客様が買うのは、機能そのものではなく、「前へ進むこと」であることが多い。これを「Jobs to Be Done（片づけたい仕事）」という見方で考えられます。
  • 「AIチャットを入れたい」という要望の奥に、「問い合わせの待ち時間を減らしたい」など、別の願いがあるかもしれません。
  • 価値は、効率だけではありません。安心、安全、信頼、成長なども、お客様にとっての価値です。
  • 数字や口コミを、先に作らない。このページの例は、すべて「説明のための架空例」です。

WHEN THIS HELPS

こんな場面で、役に立ちます。

  • お客様に「これを入れたい」と言われ、本当にそれでよいのか迷う。
  • サービスや商品が、なぜ選ばれる・選ばれないのか、言葉にしたい。
  • 新しい技術を、お客様の役に立つ形で使いたい。

EIGHT QUESTIONS

聴くための、8つの質問。

お客様の言葉は、そのまま書きとめます。そして、自分の解釈とは分けて残します。

  1. 何を達成しようとしていましたか。
  2. いつ、どんな出来事がきっかけでしたか。
  3. いまは、どう解決していますか。（AIを使っている・いない、どちらでも）
  4. その方法に、不満や負担はありますか。
  5. ほかの選択肢を選ばなかったのは、なぜですか。
  6. 何が良くなれば、「選んでよかった」と思えますか。
  7. 予算・導入・現場の運用・更新は、だれが決めますか。
  8. うまくいかなかったとき、困るのはだれですか。

NINE KINDS OF VALUE

価値は、いくつもの面があります。

機能・経済

役に立つか。費用に見合うか

課題が解決するか。導入後の運用費も含めた総費用は。

時間・安心

必要なことに時間を使えるか

短くなった時間が、別の負担に変わっていないか。不安は減ったか。

安全・信頼

守られているか。約束が守られるか

事故や情報漏えいが減るか。説明と実際が合っているか。

関係・成長

相談しやすいか。自分でできることが増えたか

依存や囲い込みになっていないか。AIがなくても理解できるか。

持続性

これからも使い続けられるか

保守できるか。他へ移る自由が残っているか。

これらを足し算して、一つの点数にはしません。安全や人権は、まず守る前提とし、そのうえで、お客様自身の優先順位で見ます。

BEFORE USING AI

道具を選ぶ前に、順番を考える。

AIは、選択肢の一つです。仕事に合う方法は、次の順番で考えてみると、見つかりやすくなります。後ろの方法ほど優れている、というわけではありません。

  1. その仕事自体を、やめられないか。
  2. 入力や手順を、簡単にできないか。
  3. 人の育成や、判断する人の決め方を見直せないか。
  4. いまある機能・検索・テンプレートで足りないか。
  5. 決まった手順は、ルールで動かせないか。
  6. あいまいな文章や下書きに、生成AIを使うか。
  7. 限られた範囲で、繰り返しの作業を任せるか。
  8. ロボットなど、現場の機械で解決する。（安全と維持費を確かめてから）

AN EXAMPLE

説明のための、ひとつの例。

説明のための架空例

「資料を自動で作りたい」と言われたとき

ある会社の担当者が「毎月の報告資料を、AIで自動で作りたい」と話します。

話を聴いていくと、本当に困っているのは「資料づくり」ではなく、「毎月の会議で、次に何を決めるのかが分からなくなる」ことでした。そこで、資料を増やす前に、会議で決めたいことを3つに絞り、必要な数字だけを一枚にまとめました。AIは、文章の下書きに使うだけにしました。

お客様の言葉の奥にあるものを見つけると、必要な道具も、変わることがあります。

実在の企業・人物・お客様の事例ではありません。考え方を示すために作った例です。

お客様の「仕事」を整理する。

AIへの頼みの例（コピーして使えます）

お客様の要望と、その背後にあり得る「片づけたい仕事」を分けてください。
事実は記録がある内容に限り、推測は「仮説」と書いてください。
少なくとも3通りの原因と、お客様に確かめるための中立的な質問を7つ、何もしない案を含む選択肢を示してください。
お客様の意図を断定しないでください。

人が行うこと：お客様本人の答えで、仮説を直す。AIの推測を、お客様が言ったことにすり替えない。お客様の個人情報や機密は入力しない。

  • お客様の言葉と、自分の解釈を、分けて書いたか。
  • AIを使わない案を、一つは並べたか。
  • 「効率」以外の価値（安心・安全・成長）も、見たか。
  • うまくいったかを、お客様自身の言葉と、実際の結果で確かめるか。
