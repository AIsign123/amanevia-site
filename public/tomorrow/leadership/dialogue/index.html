LEARNING IDEA

この講座で考えること

「よくできたところ」を具体的に認め、次の期待や必要な支援を明確にする。評価を急ぐより、本人が見ている障害や希望を聞く。尊重する姿勢と、必要な品質・納期・安全の約束は両立できます。改善点や異なる意見も、遠慮して飲み込むのではなく、相手の事情を確認したうえで、事実・影響・提案に分けて伝えます。

身近な場面（架空例）

新しい作業がうまくいかなかった。担当者が成功した部分と困っている部分を分けて話し、次回の確認ポイントを一緒に決める。

説明用の例であり、実在顧客の事例ではありません。

ONE QUESTION

まず何を理解したいか、質問の形で伝えられますか。

TRY IT AT WORK

明日の小さな実践

  1. できている行動を具体的に伝える
  2. 困難や必要な支援を確認する
  3. 改善点は「事実→影響→提案」の順に、相手の事情を聞いてから伝える
  4. 次の目標と責任範囲を短く合意する

忘れたくないこと

「ほめる」ことだけで不公正や過重負担が消えるわけではありません。
