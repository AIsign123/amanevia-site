# 公開前に代表が確認すること(Human Release Gate)

1. 4ページの本文(特に「編集長」の比喩、8つの問い、10か条)が、会社の考え方として適切か。
2. 外部リンク(全件)と利用条件。トヨタ関連は商用リンク制限のため未掲載。
3. 問い合わせ先アドレスの確定(既存トップ: akira.inadomi@amanevia.com / 新ページ: contact@amanevia.co.jp)。
4. 既存の公式トップ `/` から /tomorrow への導線を付けるか。付ける場合の文言と位置。
5. 用語集・出典DBの本来の所在(指示書の `/glossary` `/sources` と本repoの相違)。
6. canonical ドメイン(www / 非www)とサイトマップ。
7. noindex と「公開前モック」帯の解除時期(PR #1 全体の公開判断)。
8. 法務・個人情報(AI法、個人情報保護委員会FAQの扱い)の専門家レビュー。
9. 未実施のQA(キーボード・スクリーンリーダー・実機・axe)の実施。
10. 撤回条件: 誤りを指摘された場合は該当ページを即時非公開(noindex のまま・または差し戻し)にできるよう、公開は別PR・別承認で行う。
